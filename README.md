# Sistem Jadwal Kuliah

UAS Mata Kuliah Praktikum Pemrograman Web Dasar — Studi Kasus K5.

## Deskripsi
Sistem Jadwal Kuliah K5 merupakan aplikasi berbasis web yang dirancang untuk membantu mahasiswa melihat dan mengelola jadwal perkuliahan. Sistem menyediakan fitur penampilan jadwal, pencarian mata kuliah, filter berdasarkan hari dan semester, penambahan jadwal, deteksi bentrok jadwal, serta perhitungan total SKS.

## Teknologi
- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1
- Bootstrap 5.3.3

## Fitur
- Menampilkan jadwal kuliah
- Filter jadwal berdasarkan hari
- Filter jadwal berdasarkan semester
- Pencarian mata kuliah dan nama dosen
- Penambahan jadwal kuliah
- Validasi input jadwal
- Deteksi bentrok jadwal
- Penghapusan jadwal
- Perhitungan total SKS
